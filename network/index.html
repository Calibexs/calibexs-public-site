technology stack

SYSTEMS

debian & linux

Linux powers the VPS, home server, and Raspberry Pis. Systemd, SSH, and shell scripting handle everyday administration.

HOSTING

docker & nginx

Containers run selected applications while nginx handles public web traffic and static content.

CONNECTIVITY

wireguard & ikev2

Encrypted tunnels connect remote devices with the homelab. HAProxy helps route selected internal service traffic.

MONITORING

grafana & prometheus

Metrics collection, dashboards, and availability checks provide visibility into machines and services.
